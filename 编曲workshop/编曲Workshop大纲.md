# Step1 构思

哪些歌，什么主题，什么形式，大歌/小组



哪些歌：你喜欢的好听的歌



什么主题：e.g.周杰伦组曲四季，KDA，野心家

也可以没有主题just for fun，灵感和好听 e.g. shape of山歌



形式；特点；需要注意的点：

单曲；简单快速；-

medley；拼接；突出主题，注意处理转调

mashup；拼接+交错重叠；突出主题，注意处理转调，和弦需要呼应

remix；改变原曲和弦/节奏/结构；难度大，需要灵感以及充分的乐理支撑



性质；要求；特点：

大歌；全员投票，意愿足够强才能唱；气势，做好上大舞台的准备（social responsibility，需要考虑观众的接受度和传递的message）

小组；只要每个声部至少有一人即可发车；喜好driven，长度没有要求



# Step2 主旋律

打开musescore选择空白，选择乐器（选择piano，在layout里删掉一只手的谱，然后把名字改成声部名；或直接选择声部，但在mixer里调成piano的声音）

现在开始扒谱！

1. 1-7的音名唱名对应表格
2. 谱号
   1. 高中低三种谱号截图讲解，告诉大家三种谱号如何识谱
3. 调号
   1. 给大家截图所有调号并讲解调号如何分辨
4. 拍号
   1. 讲解如何读拍号，把音符时值列一遍
5. tempo
   1. 如何设置tempo
   2. 右上角可以拉动的bar有什么用
   3. 右上角可以看预估时长
6. 旋律
   1. n键开写，数字键换时值，高八度低八度，tie和sur，复制粘贴上下移动
   2. 推荐听音自己扒一遍，因为不用动脑子，而且有丰富的节奏可以练习怎么在musescore快速切换音符写谱
   3. 相对音感可以直接C调写完transpose
   4. 如果觉得扒谱太慢/听不出来，直接抄现成的谱子！先放几秒钟确认是你想要的调就可以



# Step3 和弦

1. 什么是音程，大三度，小三度，即兴三度和声是怎么做到的，举例子

2. 自己怎么找和弦？听最低音bass，因为最明显
3. 找不到听不出来怎么办？抄吉他谱！但要确认吉他是C调谱，不是的话可以找个C调谱或者自己推理一下
4. C调的每个基本和弦叫什么，长什么样，画出来，截图
5. 根据各声部range安排和弦

# Step5 如何处理转调

1. 硬转（要找一个锚点不然很难找）
2. 升高半个音
3. 找目标调的属七和弦



# Step6 如何编排得好听

下期会讲不同的arrangement，但是几个小tips：

1. 一定要写在各声部range之内

2. unison简单好使好听

3. 慎用转位

4. bass尽量不能缺席，不然很明显

5. 最高音往往是最visible的
