Google Cloud 里启用 Drive API 和 Sheets API，创建一个网页应用 OAuth 客户端，回调地址填 https://acappella-hub.elenazhang0607.chatgpt.site/api/google/callback 。用社团的 Google 账号连接一次。表格列是：曲名Song Title、编曲Arranger、学期Semester、性质Type、链接Link。链接文字是曲名，点开会打开曲名文件夹。
