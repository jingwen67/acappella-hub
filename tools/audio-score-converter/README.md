# Jingwen 本地音频转谱助手 v0.1.0

把识别出的单音低音 CSV 草稿整理成 MusicXML，再在 MuseScore 打开。它是与 MuseScore 插件并列的本地工具，不属于 Hub 网页，也不部署到 Vercel。

本版先验证「确认拍点 → 整理节奏 → 导出／打开」流程。CSV 来自音频识别结果；原唱上传、声部分离、主旋律识别尚未集成。页面可选择片段音频作本地试听，但不会分析音频。

## Mac 启动

需要 Python 3.9 或更新版本；无须安装额外 Python 包。

先更新现有仓库，再启动：

```bash
git -C "$HOME/Documents/CUCAC-Plugins/acappella-hub" pull --ff-only
bash "$HOME/Documents/CUCAC-Plugins/acappella-hub/tools/audio-score-converter/start.command"
```

也可以在 Finder 打开此目录，双击 `start.command`。系统不允许双击时使用上面的终端命令。启动会打开默认浏览器的本地页面；不是线上网站。保留终端窗口，按 Ctrl+C 停止。

## 使用

1. 选择低音 CSV，例如已经下载的 `Daoxiang_27-49_low_notes_draft.csv`。
2. 可选择对应的 22 秒片段音频，对照确认第一拍。
3. 填写速度、拍号、速度的拍单位和第一拍相对片段起点的秒数。加载后会以第一条候选时间作建议，绝不是自动确认的小节线。
4. 可在表格修改 MIDI 音高；60 是 C4。留空表示该位置开始休止，不会自动替换成和弦根音或移低八度。
5. 选择量化精度。重拍低音模式：4/4 每两拍，6/8 等复合拍每大拍，3/4、2/4 每四分音符拍。也可用四分、八分、十六分音符。
6. 选调号以控制拼写，不改变实际音高。核对设置后勾选确认并生成 MusicXML。
7. 点击「在 MuseScore 打开」。Mac 使用系统 `open -a`，由 MuseScore 正常打开新文件，不通过插件的导入接口。
8. 如果未找到应用，填写实际的 MuseScore 应用名称或 .app 路径，或下载 MusicXML 手动打开。打开后按 ⌘S 保存为 `.mscz`。

输出文件保存在 `~/Documents/CUCAC-Audio-Helper/exports/`；每次生成一个独立文件，不覆盖旧结果。点击打开后只确认系统已接收请求，不能自动验证 MuseScore 是否完成导入。

## 本次稻香草稿的试用设置

- 速度：80.75 BPM，四分音符为一拍。
- 拍号：4/4。
- 第一拍建议：片段 0.395 秒。这只是自动估计的重拍候选，仍需试听确认；不是声称原曲这一刻一定是小节第一拍。
- 量化：重拍低音（每两拍）。
- 可用 A 大调／F♯小调调号作音高拼写参考；这不负责判断和弦或调性。

按这些暂定设置，15 个候选音整理成 8 个小节，末小节用休止补齐。低音音高与原识别结果一致，不代表已经核对成准确原谱。若第一拍错半小节，请修改第一拍位置重新生成。

## CSV 格式

必需列：`midi_pitch` 与 `clip_time_seconds` 或 `start_seconds`。

```csv
start_seconds,midi_pitch,end_seconds
0,45,1
1,40,2
2,,3
3,42,4
```

`end_seconds` 可选：没有它时延续到下一个位置，末音延续一个量化单位。这是草稿时值推断，不等于原曲精确时值。有它时保留量化后的结束与休止，重叠处截断为单音线。未知音高的行可留空作休止。

## 转换规则与限制

- 量化起止时间；同一量化点的重复位置保留后一个，并提示核对。
- 保留第一拍前、少于一小节的音作为弱起；第一拍前有一个完整小节以上时提示调整。
- 生成 Bass 名称、低音谱号、Piano 音色、拍号、调号、速度、休止及跨小节延音线。
- 曲名特殊字符使用 XML 转义；输出只支持一条单音 Bass 草稿。
- 限制 4096 个输入位置、256 小节。不会识别装饰音、复杂节奏或自行确定第一拍。
- 音符识别错误仍需人工修正。将原始时间量化成整齐小节，不代表音乐分析正确。
