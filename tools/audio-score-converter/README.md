# Jingwen 本地音频扒谱助手 v0.2.0

上传完整原唱，选择片段，自动提取主旋律与伴奏低音，生成 **Solo + Bass 双声部 MusicXML**。可以直接下载，或点击按钮在 MuseScore 打开，再保存为 `.mscz`。

这是本地浏览器入口，放在同一个 repo 的 `tools/audio-score-converter/`。不属于 Hub 网页，不部署到 Vercel。音频在本机处理；首次安装依赖和下载模型需要联网。

## Mac 启动

需要 **Python 3.10–3.12**，推荐 Python 3.12。启动脚本会寻找兼容版本；Python 3.13/3.14 不用于此版固定模型环境。

```bash
git -C "$HOME/Documents/CUCAC-Plugins/acappella-hub" pull --ff-only
bash "$HOME/Documents/CUCAC-Plugins/acappella-hub/tools/audio-score-converter/start.command"
```

首次运行会创建 `~/Documents/CUCAC-Audio-Helper/runtime/` 并安装依赖，可能需要几分钟。以后直接运行同一个命令，不用重新安装。首次识别还会下载 Demucs 模型。保留终端窗口，停止时按 Ctrl+C。

也可双击 `start.command`；若 macOS 不允许，使用上面的终端命令。

## 页面使用

1. 在「上传原唱」选择 MP3、WAV、M4A、FLAC 或 MP4。文件最大 200 MB。
2. 填写原文件的起止秒数，第一版一次处理 **1–60 秒**。例如《稻香》填 27 和 49。
3. 点击「识别主旋律和伴奏低音」，等待后台任务。页面显示解码、分离、旋律、低音识别进度。
4. 完成后会**自动按建议设置生成双声部 MusicXML**，无需 CSV。可立即下载或「在 MuseScore 打开」。自动草稿默认 4/4，第一拍没有人工确认。
5. 页面保留原片段、分离人声和分离伴奏，可以对照试听。表格允许修正 MIDI 音高；60 = C4，留空表示休止。
6. 如果拍点或拍号不对，修改速度、速度的拍单位、第一拍位置和调号，勾选核对后重新生成。第一拍秒数相对于截取片段起点，不是原文件起点。
7. MuseScore 打开后可以继续修改，按 ⌘S 保存为 `.mscz`。应用未找到时，填写实际 .app 名称／路径，或下载 MusicXML 手动打开。

## 主旋律与低音怎样提取

- Demucs `htdemucs` 把原唱分离为人声、鼓、Bass 乐器和其他伴奏。
- 人声使用 Basic Pitch ONNX 提取音符。重叠候选暂取模型强度最高的一条，保留可识别的重复起音、休止与时值。Solo 用十六分音符网格整理。
- 伴奏低音来自 **其他伴奏 + Bass 乐器**，所以吉他／钢琴的和声最低音也会参与，不只查找贝斯乐器。
- 多音识别后，根据节拍脉冲建立每两拍的候选位置，结合附近一组拨弦音找最低稳定检测音。低音起音帮助选择重拍相位，不声称已识别小节第一拍。
- 自动速度可能出现倍速／半速；脉冲超过 130 时暂按半速四分音符拍解释。非 4/4 歌曲需修改设置，这版不是通用拍号／重拍检测器。
- Bass 默认按重拍网格量化：4/4 每两拍；6/8、9/8、12/8 每大拍；3/4、2/4 每四分音符拍。也可以选更细网格。
- 保留实际检测音区，不强行改成和弦根音，也不自动移低八度。

主旋律的取舍、八度、装饰音、滑音、快速咬字、和声／叠唱、伴奏低音漏检都可能有错。模型强度不是准确率。输出是可以编辑和试听的草稿，不是确认后的原谱。

## 输出与本机文件

MusicXML 包含 Solo 高音谱号、Bass 低音谱号，均为 Piano，带速度、拍号、调号、休止和延音线。两声部共享小节线与弱起长度。调号用于音高拼写，不移调。

- 生成文件：`~/Documents/CUCAC-Audio-Helper/exports/`。
- 原唱上传、分离音轨、识别记录：同目录的 `audio-jobs/`。
- 每次生成独立文件，不覆盖已有谱子；需要释放空间时可在工具关闭后手动清理旧任务目录。
- Mac 的打开按钮使用系统 `open -a`，避免调用不稳定的插件导入接口；它确认系统接收请求，不能证明 MuseScore 已完成导入。
- 识别在独立进程中执行，识别库失败时页面显示错误而不会一起退出。一次只运行一个识别任务。

## 仍可读取已有 CSV

「识别结果」里可展开 CSV 入口，单独生成 Bass。必需 `midi_pitch` 与 `clip_time_seconds` 或 `start_seconds`；可选 `end_seconds`。没有结束时间时，暂延续到下一个位置，末音延续一个量化单位。这是草稿时值安排，不等于原曲精确时值。

## 验证

```bash
python3 -m unittest discover -s tests -v
```

测试覆盖节奏量化、弱起、休止、延音线、音高拼写、双声部共享小节、主旋律候选取舍、后台任务、上传、导出和下载。使用上传的《稻香》27–49 秒做了真实 CPU 模型处理及本地 HTTP 上传—识别—导出—下载验证。测试不代表识别音高已被听辨确认，浏览器实际页面操作、macOS 安装及 MuseScore 实际导入仍需试用。

依赖使用固定版本，Basic Pitch 使用 ONNX，不安装 TensorFlow。终端关于未安装 TensorFlow／CoreML／TFLite 的提示不代表 ONNX 不可用。
